# Attribution

Parla is a personal Italian voice tutor inspired by and partially adapted from:

- **[kenoleeee/italk](https://github.com/kenoleeee/italk)** (MIT) — voice practice UX ideas and Web Speech helper patterns
- OpenRouter for LLM chat completions
- Browser Web Speech API for Italian STT/TTS

The shipped app does not include iTalk’s Gemini/Supabase stack; chat goes through a Cloudflare Worker proxy so the OpenRouter key never reaches the browser.
