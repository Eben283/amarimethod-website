📋 TO DO NEXT (15-30 minutes):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Verify Domain in Google Search Console (5 min)
────────────────────────────────────────────────────────────────────────────────
1. Go to: https://search.google.com/search-console
2. Click "Add Property" or "Start Now"
3. URL prefix: https://www.amarimethod.com
4. Verify using Google Analytics (easiest - GA4 is already installed)
5. Click "Verify"
6. Done! GSC is now monitoring your site

STEP 2: Submit Sitemap to Google Search Console (2 min)
────────────────────────────────────────────────────────────────────────────────
1. In GSC, left menu → "Sitemaps"
2. URL: https://www.amarimethod.com/sitemap.xml
3. Click "Submit"
4. Wait 24 hours for indexing
5. Check status: All 11 pages should show "Indexed"

STEP 3: Create Conversion Goals in GA4 (10 min)
────────────────────────────────────────────────────────────────────────────────
1. Go to: https://analytics.google.com
2. Select Amari Method property
3. Admin (bottom left) → Events → Create Event

Event 1: "cta_button_click" (Book Session clicks)
  - Parameter: button_text contains "Book"
  - Check ✓ when done

Event 2: "discovery_call_click" (Discovery call clicks)
  - Parameter: link_text contains "Discovery"
  - Check ✓ when done

STEP 4: (OPTIONAL) Create Conversion Funnel (5 min)
────────────────────────────────────────────────────────────────────────────────
1. Reports → Engagement → Funnel Exploration
2. Create funnel with steps:
   Step 1: Land on homepage
   Step 2: Visit booking page
   Step 3: Click "Book Session"
   Step 4: External link click (to Calendly)
